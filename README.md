# Real-time Chat

Учебный многопользовательский чат на React, TypeScript и Node.js с обменом сообщениями через настоящий WebSocket.

## Текущий этап — основа проекта

В первой публикации подготовлены:

- pnpm monorepo: `apps/client`, `apps/server`, `packages/shared`;
- строгие настройки TypeScript и ESM;
- зависимости будущих frontend и backend;
- общие типы пользователей, сообщений и статусов соединения/доставки;
- отдельные discriminated unions для клиентских и серверных событий;
- runtime-валидаторы входящих событий и общие ограничения протокола;
- настройки форматирования и MIT-лицензия.

Сервер и интерфейс появятся в следующих этапах. Текущая версия компилирует общий пакет; запускаемого чата в этой публикации пока нет.

## Стек

React · TypeScript · Vite · Node.js · ws · CSS Modules · pnpm. Автоматизированные тесты на Vitest будут добавлены отдельным этапом.

## Структура

```text
apps/
  client/              # Заготовка frontend-пакета
  server/              # Заготовка backend-пакета
packages/
  shared/
    src/index.ts       # Контракты, константы и runtime-валидация
tsconfig.base.json     # Общие строгие настройки TypeScript
pnpm-workspace.yaml    # Workspace и правила установки зависимостей
```

## Проверка текущего этапа

Требуется Node.js 22.13+ (рекомендуется Node.js 24 LTS) и pnpm 11.25.0.

```sh
npm install -g pnpm@11.25.0
pnpm install --frozen-lockfile
pnpm typecheck
pnpm build
pnpm format:check
```

Результат сборки — ESM-код и декларации типов в `packages/shared/dist`. Сгенерированные файлы не хранятся в Git.

## Общий протокол

Все события содержат `type` и `payload`. Направления разделены на `ClientEvent` и `ServerEvent`.

| Направление     | События                                                                                                            |
| --------------- | ------------------------------------------------------------------------------------------------------------------ |
| Клиент → сервер | `user:join`, `message:send`, `typing:start`, `typing:stop`                                                         |
| Сервер → клиент | `user:join`, `users:list`, `message:history`, `message:new`, `message:ack`, `typing:start`, `typing:stop`, `error` |

TypeScript проверяет код при разработке, но не сетевые данные. Поэтому `isClientEvent` и `isServerEvent` принимают `unknown` и проверяют структуру, UUID и ограничения перед использованием события.

В контракте предусмотрены nickname до 24 символов, сообщения до 500 символов, история до 1000 записей и окно дедупликации до 5000 сообщений. Реальная обработка этих событий будет добавлена в последующих публикациях.
